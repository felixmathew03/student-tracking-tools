Adding a new page

  1. Copy pages/_template.html to pages/your-page.html and write your content using the ready-made components (card, grid, tag, table, kv, note, mind map).
  2. Add one line to the PAGES list in assets/site.js. It appears here and in the top navigation of every page.
  3. Never add a <style> block. If you need a new look, add it once to assets/style.css so all pages can use it.

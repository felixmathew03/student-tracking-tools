Shared UI building blocks

  • App shell: role-based sidebar, top bar with global student search, notification bell, profile menu. Mobile-first layout for the student portal, desktop-first for staff.
  • List page: search + filters + table + pagination + "Create" button (opens a modal or drawer; no separate form pages).
  • Detail page with tabs: Student 360, Batch Detail, Drive Pipeline.
  • Reason dialog: required for attendance corrections, result changes, batch transfers, payment corrections. It writes to the audit log.
  • Route guard: checks the role's permission keys; restricted screens (conduct, grievances) are hidden from the sidebar for other roles.
  • Common widgets: status badge, file uploader (signed URL), confirmation dialog, empty state, toast.
